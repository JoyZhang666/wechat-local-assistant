# v1.13.0-rc.3

2026-10-17（Asia/Shanghai）；技术用户源码正式版准备候选，保留RC。

- 新安装补齐专用Python初始化：命令行必需步骤及界面按钮，不修改系统防火墙或自启。
- 内置读取器增加本人ID与账号目录绑定，剥离设备后缀，拒绝错误归属；旧内置授权需重新确认，外置生产配置保持。
- 普通用户正常打开并登录微信，点“连接／刷新”；程序自动发现官方程序、账号及记录位置，已有授权复用。首次必要时单独确认本机监听，验证后DPAPI保存；不要求找文件夹、填写账号或先退出重开。成功自动加载列表，手动导入默认隐藏在高级排错中。
- V2图片新增离线样本验证与接入，不读取进程；现有不匹配授权保持。布局、数量、超时及媒体字节／像素有明确限额。
- 修复子进程创建、分配Job或写入失败时的句柄／进程清理；取消和退出覆盖接入工作线程。
- 限制单条压缩消息解码为8MiB，超限明确停止、不截断冒充完整；XML拒绝DTD／实体声明，保留原数据库。
- 新增可选ASR配置模板、固定来源／下载／校验步骤；配置SHA-256时在启动前校验文件，兼容旧配置但不冒充已核验。
- Frida为单独可选依赖，保留上游MIT取钥核心与Frida自身许可；源码不附原生库、模型或私人材料。

合成测试与自有子进程中的Frida夹具不等于真实微信兼容验收。新Windows用户首次接入、真实单聊／群聊、真人语音和三后端整链验收尚未闭环，不能去除RC尾标。
