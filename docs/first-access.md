# 本人首次接入与媒体组件

版本：v1.13.0-rc.3；2026-10-17（Asia/Shanghai）；技术用户源码候选。

## 微信数据库辅助接入

1. 和往常一样打开Windows微信并登录，保持运行；不需要先退出重开，也不用查找账号目录或程序文件。
2. 在助手“二、选择聊天”点击“连接／刷新”。首次出现本机连接窗口时确认本人授权，再点“连接微信”；之后已有授权正常复用，无需每次重新接入。
3. 程序自动发现当前用户的微信实例及程序位置，检查腾讯签名；只检查微信约定位置、当前用户存储设置和已运行客户端的文件位置线索，不递归搜索磁盘。先复用已授权、可验证的账号，旧内置授权可重新校验并纠正设备后缀，无需用户复制密钥。
4. 首次必要时用固定Frida 17.23.1临时监听微信正常登录／数据库打开。使用前在本项目venv安装`requirements-access.txt`；程序不强关、不自动重启、不常驻。候选只经数据库认证匹配账号，再解除附加、完整验证后DPAPI保存；多个匹配不按文件新旧猜测。
5. 从主窗口发起连接后，成功会自动加载聊天列表。选择聊天和时间后处理。现有外置部署原样保留，仍用原授权直接刷新，不迁移其配置。

首次监听可能受微信版本、已经完成的登录时机或特殊存储方式影响；等待超时会停止、保留旧授权，不退回要求普通用户找目录。该路径仍需真实新用户验收，不承诺所有4.x版本。安装、引导及模块导入不取钥；首次提取需本人当次确认，不复用开发机许可。日常读取已有授权不重复取钥。

只有排错时才展开设置页“高级排错／手动导入”；默认隐藏，不属于普通用户流程。不要把密钥发给Agent、命令行、聊天或Issue。

## 图片单独离线接入

在“图片解码”点击“协助接入图片（离线验证）”，由本人选择账号目录及2—9张不同内容的V2加密JPEG文件，可选微信目录内文件或已导出包的加密副本。独立确认后，程序在90秒限额内依据所选目录元数据和样本离线派生，逐张通过填充、格式和像素验证后DPAPI保存；不扫描微信进程、不联网、不展示密钥。

只支持带4位十六进制设备后缀的`wxid`目录及1024字节加密头的兼容V2 JPEG布局。最多9张／总计128MiB，单图64MiB、4000万像素。重复样本、不支持布局或错误会停止。已有授权匹配则复用，不匹配则保留并提示核对，不自动覆盖为另一账号；高级手动入口保留。

重新预览并导出，在HTML核对图片归属。只有缩略图时保留并标明；未下载、不支持容器或验证失败列入缺口。数据库、图片、会员是三种独立授权。

## 可选Qwen语音组件

先安装`requirements-voice.txt`以解码SILK。Qwen采用固定1.7B Q8 GGUF及匹配audio projector，不随源码下载。每条最多60秒，超限保留原件并标注。先验证CPU，再测试Intel Vulkan GPU，不承诺NPU或全部运算都在GPU。

1. 从[固定模型修订](https://huggingface.co/ggml-org/Qwen3-ASR-1.7B-GGUF/tree/36a678687ba7d07a74ca70ccb0e36902e005fb80)下载`Qwen3-ASR-1.7B-Q8_0.gguf`与`mmproj-Qwen3-ASR-1.7B-Q8_0.gguf`。用`Get-FileHash -Algorithm SHA256`逐一核对[配置模板](../config/asr-runtime.example.json)中的两个哈希。
2. 从[llama.cpp b11516发布页](https://github.com/ggml-org/llama.cpp/releases/tag/b11516)下载`llama-b11516-bin-win-vulkan-x64.zip`（上游预览构建）。整个ZIP的SHA-256应为`01dff69c02650624d401be0b170348ea38f4bcdca24cb97a7415cddb7315414b`。通过后解压到独立`llama/`目录，保留匹配的DLL。
3. 将模板复制为模型目录中的`runtime.json`。路径相对该目录，填入从已验证ZIP解出的`llama-mtmd-cli.exe`的SHA-256；不能填ZIP哈希。模板占位未替换会拒绝运行。
4. CPU保留`device=none`；核对驱动、设备编号后可改`Vulkan0`。GPU卸载不能从日志证实时会报错。界面“本机与媒体”填写模型目录，先用自己的短录音检查日期、否定、数字和人物。

存在`sha256`配置时，程序启动ASR前流式核验exe、model、mmproj。另有`vad_model`时也须列其哈希；VAD需另装`requirements-asr.txt`及相应权重。该检查不替代上游ZIP和DLL来源核验。旧配置不带`sha256`仍兼容，但不标为完整性已验证；版本号本身不是校验。原语音应保留用于复核。
