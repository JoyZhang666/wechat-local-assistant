# 微信本地助手

选择微信聊天和时间范围，生成有原文依据的主题摘要，或保存为可离线阅读、供 Agent 继续处理的聊天记录包。

**v1.13.0 · Windows 技术用户源码版 · MIT**

[下载源码](https://github.com/JoyZhang666/wechat-local-assistant/releases/tag/v1.13.0) · [安装说明](docs/public-install.md) · [首次接入与媒体配置](docs/first-access.md) · [反馈问题](https://github.com/JoyZhang666/wechat-local-assistant/issues)

## 能帮你做什么

| 你的目标 | 得到什么 |
|---|---|
| 快速读懂一段讨论 | 按主题整理要点、决定、待办和未解决问题，并附原文引用 |
| 长期保存重要聊天 | HTML 阅读页、Markdown、结构化记录及可恢复的媒体文件 |
| 交给下一步 Agent 处理 | 保留消息顺序、来源和识别结果，继续写纪要、整理行动清单 |

## 核心亮点

- **范围由你选**：指定单聊或群聊、开始和结束时间，先预览数量再处理。
- **摘要可追溯**：程序从原文提取引用；分段检查点支持中断后续接。
- **原文与识别结果分开**：支持图片呈现、图片理解及语音转写；缺失和不支持的内容列入清单。
- **三种文字模型连接**：本地 Ollama、云端兼容 API、ChatGPT／Codex 会员授权。
- **完整资料包**：离线 HTML 方便阅读，结构化记录方便后续处理。保存时带上整个文件夹。
- **按需运行**：不注册开机启动，不新增常驻监控；结束时释放本程序启动的模型与请求进程。

## 快速开始

需要 **Windows、含 Tkinter 的 Python 3.12**，以及可运行终端命令的基础。源码包不含一键安装器、模型或微信数据。

1. **安装并打开**：按[安装说明](docs/public-install.md)创建独立环境、安装所需依赖、初始化专用运行程序。
2. **配置一种文字模型**：在“选择模型与连接方式”保存私人数据目录及所选模式。首次打开也可跟随“新手引导”。
3. **登录微信并连接**：正常打开 Windows 微信，登录本人账号，点击“连接／刷新”；首次按提示确认本机授权。日常连接自动识别，无需手动找目录。
4. **选择范围**：勾选聊天、设定时间，点击“预览数量”。结束时刻不包含在范围内。
5. **生成或导出**：A 页生成摘要；B 页对单个聊天执行识别并导出，也可追加摘要。
6. **阅读全文并保存**：打开完整 HTML，核查引用和媒体缺口；保存整个资料包，包含 `media/` 与 `manifest.json`。

首次微信接入受客户端版本和登录时机影响；失败时按界面提示处理，不会强制关闭微信。[接入说明](docs/first-access.md)

## 模型怎么选

| 方式 | 适合谁 | 需要准备 |
|---|---|---|
| 本地 Ollama | 希望内容留在本机 | Ollama、兼容模型及相应内存；模型单独安装 |
| 云端兼容 API | 已有模型 API 服务 | 支持 Chat Completions 与 JSON 模式的 HTTPS 地址、模型名和 API Key；独立计费 |
| ChatGPT／Codex 会员 | 使用符合条件的 OpenAI 账号 | 安装会员依赖，在官方页面亲自授权，选择服务返回的模型；受订阅、账号及服务限制 |

云端模式每次处理前确认发送范围。图片与语音识别在本机进行；**识别后的文字若纳入云端摘要，也会发送至所选服务**。会员授权不导入其他工具的凭据，也不承诺无限额度。

本地文字模型以约 12B 量化模型为参考，已测配置为 **32GB 内存、Intel Core Ultra + Arc 140V**。Intel GPU 使用取决于 Ollama 的 Vulkan 支持、驱动和模型配置；CPU 路径仍需保留。本版不提供 NPU 加速，不保证其他机器的速度或兼容性。仅用云端文字摘要时无需部署本地文字模型。

## 媒体能保留到什么程度

| 内容 | 支持与前提 |
|---|---|
| 文字 | 保留所选范围内可读取的消息；摘要引用可核对原文 |
| 图片 | 本机原件可获取且格式、密钥兼容时恢复呈现；理解图片另需本地视觉模型 |
| 语音 | 保留可获取的录音；转写需本地解码、ASR 程序及模型 |
| 视频、文件等 | 尽可能保留可获取原件与消息元数据，不承诺理解全部内容 |
| 缺失或不支持 | 明确标注缺口，不补写为已恢复或已识别 |

图片密钥与数据库密钥独立。可选组件需要单独配置；v1.13.0 尚未提供完全独立于模型配置的“纯原记录导出”入口。[配置详情](docs/first-access.md)
