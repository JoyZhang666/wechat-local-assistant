# 本地微信摘要

版本：v1.13.0；更新：2026-10-17（Asia/Shanghai）；技术用户源码正式版。

用于配套应用的安装检查、启动和指定任务操作。不含模型或用户数据；应用提供本人逐次授权的辅助接入，手动导入为高级备用。先找到应用根目录并读取`README.md`（开发目录为`README.public.md`）及`docs/public-install.md`。不要根据Skill位置猜测应用已安装。

## 默认使用方式

云端配置后可在左侧“一、模型”区域点击“连接测试”；它仅发送三条内置虚构消息，不读取微信，并需用户当次确认。CLI为 `cloud-test --job <新32位任务ID> --allow-cloud --config <私有配置>`，不覆盖已有任务。当前支持独立API Key和会员OAuth两条路径；会员须由用户在官方页登录授权，不可读取或复制Codex/OpenClaw的Token来代替。

1. 使用应用配置中的 Python 与私有配置文件，运行 `scripts/wechat_ui.py --help` 核对当前参数。可用命令为 `gui`、`status`、`list`、`prepare`、`generate`、`cancel`、`export`、`save-export`；配置由 `--config` 指定，已有任务由 `--job` 指定。
2. 可运行 `status` 检查私有配置是否能解析；此命令不验证微信读取组件、模型、ASR、防火墙或识别质量，不据此宣称组件就绪。默认 CLI 返回状态、数量、不透明任务 ID 和报告路径，不返回联系人名单、聊天正文或摘要。
3. 打开 `gui`，让用户本人选择联系人／群聊、时间范围并预览数量。新GUI会在生成阶段先进行本机媒体识别；云端确认须明确包含识别后的文本。完整导出可只识别，或通过 `export --summarize` 追加摘要；云端追加还需 `--allow-cloud`。不要为了代替用户选择而读取真实聊天列表或本机数据库。
4. 用户在本机确认预览后生成摘要。结果留在本机界面或报告文件；只向 Agent 对话报告执行状态、完成数量和可打开的本机报告路径。除非用户明确要求并授权将指定内容交给当前 Agent，否则不要打开报告正文或打印它。
5. 对已有、由用户明确指定的任务，可用 `generate --job <任务ID>` 继续，或用 `cancel --job <任务ID>` 取消；ID 必须是该应用已创建的32位十六进制编号，不能传目录路径。不要猜测任务 ID、重放历史队列或扩大聊天范围；选择及时间变化必须重新预览。

## 数据和授权边界

- 会员方式使用本助手的独立OAuth注册/登录。只有用户选择后才启动 `member-login` 官方网页授权；CLI需要新任务ID，可用 `--member-account` 指定已保存的本助手账户。`member-models`刷新当前目录，`member-logout`撤销本助手可续期会话并清除本机令牌；这些操作不等于允许读取真实聊天。不要导入其他工具的凭据，不在对话中索取回调URL、授权码、Token或账号文件。
- 会员模型选择来自该账户返回列表，真正完成Responses请求才能确认访问。与Codex/ChatGPT Work共用额度；不要自动开启额外积分、提高限额或在额度不足时改走API计费。会员与API一样，真实摘要外传仍需当次确认；合成测试只发送内置虚构数据。

- 模型、账号配置、DPAPI 密钥、消息缓存、任务快照、日志和摘要属于当前用户的私有数据目录，不能进入 Skill、Git 仓库或发布包。
- 新机器推荐内置后端，由本人操作独立辅助接入窗口并逐次授权；安装依赖和打开设置均不执行取钥。其他机器的同意不适用；此Skill本身不执行Frida或强制退出微信。媒体接入另见docs/first-access.md。
- 默认使用本机回环模型；用户可以在“模型与本机设置”选择云端文字摘要，填写HTTPS Base URL、模型名和API Key。Key只在本机界面填写并由DPAPI保护，不在聊天中索取。每次生成前必须由用户确认本次发送范围，CLI仅在取得针对该任务/服务的授权后加 `--allow-cloud`；保存配置或旧授权不自动授权新的发送。不要代替用户猜Key、选择真实聊天或自动测试云端。模型错误只报错，不自动切到其他后端。图片/语音仍用本地组件；不要关闭本地出站限制或修改代理规则。
- 只在用户需要时启动界面和推理。不开机自启，不创建定时任务，不运行额外常驻监控；结束或取消后核验本次模型任务已释放。
- 摘要入口处理文字并报告非文字跳过数量；单聊天导出可以保留本机可恢复媒体和独立识别注释。Gemma 图片理解与媒体导出组件、完整合成导出整合已通过开发机验证；Qwen GPU 和 Silero CPU VAD 完成有限的冻结合成音频测试，ASR单元测试为mock。真实微信媒体和 GUI 用户操作尚未整体验收。缺失、未读取、未支持或识别失败须明确显示，不能表述为已经理解或完整。本机未保存的历史记录不能补齐。

## 安装、更新和分发

按照应用发布文档使用独立环境与合成示例验证，再进行用户本机验收。不要将这个 Skill 安装到全局目录、下载模型、升级驱动、删除旧软件或发布到 GitHub，除非用户明确请求对应操作。

分享前运行应用的白名单构建脚本，只交付其生成的源码包和校验值。检查 `RELEASE-STATUS.txt`、`LICENSE` 与 `LICENSE-SCOPE.md`；MIT 仅覆盖独立新写部分，原供应包及第三方读取组件不随包提供。包生成、发布检查和真实用户验收是不同结论。

Qwen3-ASR-1.7B Q8 GGUF、匹配音频投影、llama.cpp b11516 Windows Vulkan 预览程序、Silero VAD模型及私有 `runtime.json` 不属于 Skill 或公开源码包；只使用用户已单独部署并验证的 `asr_model_dir`。`requirements-asr.txt` 是可选CPU门禁依赖，不由GUI安装自动执行；需另获对应安装授权。已配置的 `vad_model` 检测完整音频，判为非语音时不调用Qwen，结果应标为Silero模型的衍生判断，不写成Qwen转写。VAD可能误拒低声等语音，须保留原录音供本机回听，不能将无人声判断当人工核验。FireRed 完整 AED INT8 保留为 CPU 对比资产，其权重和运行程序也不捆绑。适配器开发或评估未完成时，不因源码检查通过就宣称真实语音质量或完整用户流程已验收。

## 独立聊天导出

用户选择一个联系人／群聊及时间范围后，可以在本机执行 `export`，生成 JSONL、Markdown、HTML 和阅读说明。原始记录与模型识别的图片／语音注释分离；媒体缺失、未知类型或识别失败必须在清单中说明，不能称为完整备份。媒体识别仅采用该安装已经明确配置并验证的本机组件，不自动下载、取钥或联网补齐。

导出包包含真实聊天和可能的媒体原件，属于私有资料；它不是公共源码包，不进入 GitHub、Skill 或项目发布白名单。默认只报告导出状态、数量和目录，不能打开正文后回传到云端 Agent；对导出包的外传、分享或由当前 Agent 阅读，都须有用户针对具体内容的明确要求。

导出后选择“保存完整记录包”和父目录，保存新命名的完整文件夹；“打开阅读页”在浏览器打开本机 `index.html`，不自动播放媒体。整个文件夹才能保留相对媒体链接。对用户已指定的导出任务，`save-export --job <任务ID> --destination <新目录>` 只复制完成文件及清单媒体，不读取微信、不运行模型、不覆盖旧目录；不会补齐缺失内容。旧包保留原排版，新导出才采用Markdown图片显示和可读注释。

摘要自动保存Markdown、结构化事实及离线HTML。“打开完整摘要”使用完整浏览器页面，“打开摘要目录”定位报告；“另存完整摘要包”保存相对路径和校验清单，另存Markdown选项仍保留。依据编号及原文采用引用块。历史摘要只读取已保存报告；启动不自动刷新微信，需读聊天时由用户点击刷新。`render-summary --job <报告目录ID>`及`save-summary --job <报告目录ID> --destination <新目录>`不读微信、不运行模型，不携带内部结果路径、检查点、凭据或原媒体。旧原文件保留，部分任务不标为完整。阅读或保存不授权外传；只能向Agent返回元数据与路径。
